# Frontend

The browser-facing pages are grouped by feature so each page is easy to find.

- `templates/assets/` — asset list, details, add/edit forms, bulk upload and QR print.
- `templates/authentication/` — sign-in, password change/reset and MFA.
- `templates/dashboard/`, `templates/team/`, `templates/history/`, `templates/verification/` — feature pages.
- `templates/shared/` — shared page frame and error page; `shared/partials/` contains reusable form pieces.
- `static/css/shared/` — shared look and theme.
- `static/js/shared/`, `static/js/dashboard/`, `static/js/verification/` — shared scripts and feature-specific browser behavior.
